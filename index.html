User Instructions & Mathematical Basis

This software automates the mass and enthalpy balances for a triple-effect backward feed evaporator system.

  • In backward feed mode, fresh feed solution enters the coolest effect ($F_1 = L_3$, Effect III) and flows sequentially toward Effect I ($L_2 \rightarrow L_1$), where the final concentrated product exits. Fresh steam ($W_1$) enters Effect I.
  • Enter all operating parameters in SI units in the input fields below and click "Solve Heat Balance".
  • The system formulates mass balance equations: $$\text{Solute Balance: } F_1 x_{F1} = L_1 x_{S3}$$ $$\text{Overall Material Balance: } F_1 = L_1 + V_1 + V_2 + V_3$$
  • Simultaneous energy equations are solved dynamically using linear algebra matrix elimination.
  • Use the toggle in the results section to switch output display between SI Units ($\text{kg/s}$) and British/Imperial Units ($\text{lb/h}$).
